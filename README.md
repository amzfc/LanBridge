# 邻传

任意两台 Mac 或 Windows 电脑之间直接传送文件、文件夹的桌面软件。支持 Mac↔Mac、Windows↔Windows 和 Mac↔Windows。两台电脑连接同一局域网，任意一端输入另一端显示的 IP 和六位配对码，双方核对校验码并确认。配对后选择设备，拖入文件或文件夹即可发送；接收方手动确认后开始传输。

## 使用

1. 在两台电脑上打开邻传。接收连接的一端把界面上的 IP、端口和六位配对码告诉另一端。另一端输入 IP 和配对码，发起配对。
2. 双方核对页面上显示的四组校验码完全相同，然后分别点击确认。只需首次配对；设备身份保存到各自本机。
3. 选中已信任的电脑，拖入文件或文件夹。对方点击“接收”后开始传输。文件保存在“下载/邻传接收”内的独立目录，避免覆盖同名文件。

默认 HTTPS 端口为 **53319**。如果系统防火墙询问是否允许邻传接收局域网连接，请允许。两台电脑应处于能互相访问的网络；某些访客 Wi-Fi 会隔离设备，需改用普通 Wi-Fi 或有线局域网。已配对设备的 IP 改变时，点击“更新 IP”。

## 开发与打包

需要 Node.js 22 或更新版本。

```sh
npm ci
npm start
npm test
npm run dist:mac
npm run dist:win
```

macOS 打包在 macOS 上运行，Windows 打包在 Windows 上运行。`.github/workflows/build.yml` 可在 GitHub Actions 两个平台分别构建，结果作为工作流 artifact 下载。macOS 压缩包未经 Apple 签名及公证，首次运行需要在系统设置中允许。Windows 便携版未代码签名，SmartScreen 可能提示。

## 安全与限制

所有文件通过直接 HTTPS 连接发送。首次配对采用六位临时码、双方显示的 64 位校验码以及手动确认；随后会记住对方的设备证书，并拒绝证书不匹配的连接。单次传输最多 10000 项、10 TB。支持普通文件与文件夹，不跟随符号链接；文件传完会进行 SHA-256 校验。传输中断会显示失败，首版尚不支持断点续传。网络地址入口目前支持局域网 IPv4。
